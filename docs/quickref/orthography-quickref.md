## 2. Consonants

### 2.1 Single-letter and digraph consonants

| Grapheme | IPA | Notes |
|---|---|---|
| `s` | /s/ onset, /z/ elsewhere | See §2.2. |
| `ś` | /s/ | Non-onset devoicing mark (not used in onset). |
| `š` | /ʃ/ | Caron (retired in favor of `sh`). |
| `r` | /ɾ/ | Alveolar tap — the common rhotic. |
| `rh` | /ɻ/ | Retroflex approximant, **onset**. Non-onset /ɻ/ = `rr` (§2.6). |
| `sh` | /ʃ/ | Digraph (`h` is the digraph-former: `rh`, `th`, `sh`). |
| `þ` | /θ/ | Thorn. |
| `ð` | /ð/ | Eth. |
| `y` | /j/ | Palatal approximant (not a vowel). |
| `w` | /w/ | Labio-velar approximant (mostly in clusters). |

Other consonants (`b t k l h n m` …) take expected values; `k`/`l` occur only in clusters; aspiration unwritten (except `th`, §2.7).

### 2.2 The `s` / `ś` / `ss` system

| Form | Reads as | Context |
|---|---|---|
| `s` | /s/ | onset; **or** non-onset adjacent to a voiceless obstruent (`p t k`, `ts`) |
| `s` | /z/ | non-onset elsewhere (default; incl. word-final — **no** final devoicing) |
| `ś` | /s/ | non-onset, marks a true /s/ where /z/ is the default |
| `ss` | /sː/ | geminate (voiceless), any position |

### 2.3 Devoicing diacritic (acute on consonant)

| Grapheme | IPA |
|---|---|
| `ń` | /n̥/ |
| `ḿ` | /m̥/ |
| `ŕ` | /ɾ̥/ |
| `ś` | /s/ (devoiced /z/, non-onset) |

### 2.4 Gemination (doubled consonants)

| Grapheme | IPA |
|---|---|
| `ss` | /sː/ |
| `nn` | /nː/ |
| `pp` | /pː/ (predicted; currently **unattested** — *epplii* reanalyzed → *eplii*, v3.9) |

Generalizes to any future `CC` = /Cː/. **Carve-outs:** `rr` = /ɻ/ (§2.6), `tt` = /ʔ/ (§2.7) — neither is a geminate. Labialized geminate /kʷː/ = `cqu` ~ `kkw` **[Open: standardize]**.

### 2.6 Positional rhotics

| Grapheme | IPA | Position |
|---|---|---|
| `r` | /ɾ/ | tap, all positions |
| `ŕ` | /ɾ̥/ | devoiced tap |
| `rh` | /ɻ/ | onset |
| `rr` | /ɻ/ | non-onset (coda, intervocalic; incl. linking *r*) |

### 2.7 Glottal stop & aspiration

- `tt` = /ʔ/ in all non-initial positions; the IPA `ʔ` is never orthographic.
- `th` = /tʰ/ (aspiration otherwise unwritten); generalization to all aspirated /t/ **[Open]**.
- Pre-consonantal /ʔ/ (*hoʔnʔnts* type) **[Open]**.
- Expressive class: a single `t` may = /ʔ/; onomatopoeia-object marker `-ðs` (< *this*).

## 3. Vowels

### 3.1 Short vowels

| Grapheme | IPA | Notes |
|---|---|---|
| `i` | /ɪ/ | short lax |
| `ii` | /i/ | short tense (gliding /ɪi/); single syllable |
| `e` | /ɛ/ | |
| `a` | /ɑ/ | |
| `o` | /o/ | |
| `ä` | /æ/ | residual /æ/ (diaeresis; formerly `æ`) |

Bare `u` is not a grapheme (only as the 2nd element of a `Vu` digraph). **Fold hierarchy:** ogonek > pitch/quantity mark > diaeresis.

### 3.2 Long vowels: `Vu` digraphs + `iiy`

| Grapheme | IPA | Source |
|---|---|---|
| `au` | **/ɑ/** | smoothed `a`+ə — surfaces **short** (the `Vu` exception, v3.7) |
| `eu` | /ɛː/ | smoothed `e`+ə (also /æ/-before-nasal) |
| `iu` | /ɨː/ (phon. /ɪː/) | GA /u/ unrounded/fronted, reanalyzed as length |
| `ou` | /oː/ | smoothed `o`+ə (also /au, or/→/oː/) |

`iiy` = /iː/ (from /ɪji/-smoothing). Long /ɑː/ (future `aa`) deferred.

### 3.3 Hiatus & `ii` contrasts

Doubled vowels = **hiatus**: `aa` /a.a/, `ee` /e.e/, `oo` /o.o/. Genuine /i.i/ = `iyi`.

| Grapheme | IPA | Type | Morae |
|---|---|---|---|
| `ia` | /ia/ | diphthong, monosyllabic | 1 |
| `iia` | /i.a/ | hiatus, disyllabic | 2 |
| `iie` | /iɛ/ | long diphthong, monosyllabic | 2 (single nucleus) |
| `ea` | /e.a/ | hiatus, disyllabic | 2 |

### 3.4 Diphthongs

`ei` = /ei/ (monomoraic). `oë` = /oe/ (bimoraic long diphthong; plain `oe` = hiatus /o.ɛ/). A mark on the digraph supplants the diaeresis (*rhibôet*).

### 3.6 Nasalization

**Tilde** (close-front + approximants): `ĩ` /ĩ/, `ỹ` /j̃/, `w̃` /w̃/.

**Ogonek** (open/mid): `ą` /ɑ̃/, `ę` /ɛ̃/, `ǫ` /õ/.

**Long nasals** (ogonek on `u`): `aų` /ɑ̃ː/, `eų` /ɛ̃ː/, `ių` /ɨ̃ː/ (phon. /ɪ̃ː/), `oų` /õː/.

Placement: pitch acute on V₁ (historical-stress), nasalization on V₂. Predictable glide-nasalization left unmarked (*ęy* = /ẽj̃/, not `ęỹ`).

### 3.7 Pitch and stress

- **Acute** `´` = pitch (always written; lexical). **Grave** `` ` `` = stress (predictable/final; formal only). **Circumflex** `^` = pitch+stress coincidence (formal only).
- **`ii`-digraph rule:** a mark on one element of `ii` → the other written dotless `ı` (*béntsıìy*). In `iiy`, grave on the 2nd `i`, the `y` never marked.

| GA etymon | IPA | Casual | Formal | Pitch | Stress |
|---|---|---|---|---|---|
| *Emma* | /ɛma/ | `éma` | `émà` | /ɛ/ | /a/ |
| *Emily* | /ɛmiː/ | `émiiy` | `émıiìy` | /ɛ/ | /iː/ |
| *Betty* | /bɛi/ | `béi` | `béì` | /ɛ/ | /i/ |
| *Jennifer* | /rɛ̃ːθw̩/ | `réųþw` | `réųþẁ` | /ɛ̃ː/ | syll. /w̩/ |
| *carrot* | /r̥eːʔ/ | `ŕéutt` | `ŕêutt` | /eː/ | /eː/ (coincide) |
| *barn* | /beːn/ | `béun` | `bêun` | /eː/ | /eː/ (coincide) |
