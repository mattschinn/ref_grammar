Triggers are postfix — type the base letter first, then the trigger. Invalid combinations silently fail (the trigger is dropped). Capitalization of the base letter is preserved. When one element of an ii digraph takes any diacritic, the other automatically becomes dotless (ı) — e.g. ii~ → ıĩ, ii4 → ıì, ii` → ıí.
Capital-letter triggers J, V, Q: these are consumed as diacritic markers only in non-word-initial position — at the start of a word they render as literal letters. Lowercase j, v, q are always literal letters.
Stack diacritics toggle: when ON, multiple triggers on the same letter stack (e.g. acute on a nasalized vowel). Stacked rules are checked against the original base letter. Ligatures can also stack (a3` → ǽ). With strict mode ON, stacks that have no precomposed Unicode form are silently skipped. When OFF (default), only the first diacritic on each letter is applied.
Strict mode: Some combinations (like x with most diacritics) have no precomposed Unicode form and render as two code points (base + combining mark). With strict mode on, these are skipped. Affected combinations: x with acute; w with tilde.
